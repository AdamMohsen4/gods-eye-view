# Earthnow API contract

Types live in `shared/src/types.ts` (`@earthnow/shared`). All JSON. The server
listens on `PORT` (default 8787); the Vite dev server proxies `/api` and
`/share` to it.

## Identity (until Clerk lands)

Every request sends `x-guest-id: <uuid v4>` generated by the client and kept
in `localStorage`. The server upserts a guest user for it; no personal data is
collected. Requests without a valid id get `401 {error:"guest_id_required"}`
on endpoints that need a player.

## Player endpoints

| Method | Path | Body | Response |
| --- | --- | --- | --- |
| GET | `/api/me` | – | `MeResponse` |
| PUT | `/api/me` | `{displayName?, country?}` (country = ISO-3166 alpha-2 or null) | `MeResponse` |
| DELETE | `/api/me` | – | `204` (GDPR deletion of all rows for this guest) |
| GET | `/api/daily/today` | – | `DailyToday` (no answers) |
| POST | `/api/rounds/start` | `{snapshotId, mode:"daily"}` | `StartRoundResponse`; idempotent while unguessed; `409 {error:"already_played"}` after a guess |
| POST | `/api/rounds/:roundId/clue` | – | `ClueResponse`; `409 {error:"no_more_clues"\|"round_closed"}` |
| POST | `/api/rounds/:roundId/guess` | `{guess: {lat,lon} \| null}` | `GuessResponse` (truth + score). Timer is checked server-side: daily rounds allow `ROUND_TIMER_SECONDS` + 5 s grace; late guesses score 0 with `timedOut:true`. `409 {error:"already_guessed"}` |
| GET | `/api/arcade/next` | – | `StartRoundResponse` (no timer, `deadline:null`); `429 {error:"arcade_limit", limit}` when the free daily allowance is used |
| GET | `/api/daily/:date/summary` | – | `{date, number, total, rounds:[{type, score, guess}]}` for the caller (used by the results/share screen) |
| GET | `/api/leaderboard?scope=global\|country&date=YYYY-MM-DD` | – | `{date, scope, rows: LeaderboardRow[], you: LeaderboardRow \| null}` (top 50) |
| GET | `/api/attributions` | – | `Attribution[]` for the About page |

## Share

| Path | What |
| --- | --- |
| `GET /share/:number/:userId` | HTML with Open Graph/Twitter tags pointing at the PNG; a visitor is redirected to `/?ref=share&d=:number` (opens the Daily, no sign-up wall) |
| `GET /share/:number/:userId.png` | 1080×1350 card: dimmed world, the player's five pins, no true locations |

## Admin (header `Authorization: Bearer $ADMIN_TOKEN`)

| Method | Path | What |
| --- | --- | --- |
| GET | `/api/admin/daily/:date` | Daily with full snapshots (truths included) |
| POST | `/api/admin/daily/:date/generate` | (Re)generate an unpublished daily |
| POST | `/api/admin/daily/:date/swap` | `{index, snapshotId}` replace one round (unpublished dailies only) |
| GET | `/api/admin/snapshots?type=&limit=` | Candidate snapshots |
| POST | `/api/admin/users/:id/ban` | `{banned: boolean}` |

A daily is *published* (locked) once its date is today or earlier.
